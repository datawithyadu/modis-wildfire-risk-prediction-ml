# MODIS Wildfire Risk Prediction using Machine Learning

## Project Overview
This project builds a machine learning model to predict wildfire risk using satellite data from the MODIS (Moderate Resolution Imaging Spectroradiometer) dataset.

The goal is to help identify areas with a high probability of wildfire occurrence using environmental and satellite-derived features.

## Problem Statement
Wildfires cause significant environmental and economic damage every year. Predicting wildfire risk using satellite data and machine learning can support early detection and decision-making.

This project develops a predictive model and an interactive dashboard to analyze wildfire risk.

## Dataset
Source: MODIS Satellite Data

The dataset contains environmental indicators such as:

- Temperature
- Vegetation index
- Fire radiative power
- Latitude
- Longitude
- Detection confidence

These features help identify conditions where wildfire is likely to occur.

## Machine Learning Models
The following models were implemented:

- Random Forest
- XGBoost

Hyperparameter tuning was performed to improve model performance.

## Model Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC AUC
